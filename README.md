# EZProxy Skins for the MBLWHOI Library

Repository for EZProxy skin files used by the MBLWHOI Library.

## Overview

This repository contains customized skin files for the EZProxy authentication service, tailored for the MBLWHOI Library. These files define the look and feel of the EZProxy login and error pages, ensuring a consistent user experience for library patrons.

## Contents

- Custom CSS stylesheets
- HTML templates for login, error, and informational pages
- Branding and accessibility enhancements

## Usage

1. Download or clone this repository.
2. Copy the required skin files (HTML and CSS) into your EZProxy server's skin directory.
3. Update your EZProxy configuration to reference these custom skins.
4. Restart EZProxy to apply the new look.

## About EZProxy

[EZProxy](https://www.oclc.org/ezproxy/en.html) is a proxy server that provides remote access to library resources.
